INSTALACION DEL PORTAL EN LA PC
================================

Requisitos:
1. Node.js 22 o superior: https://nodejs.org/es/download
2. XAMPP con MySQL: https://www.apachefriends.org/es/index.html

Pasos:
1. Copia esta carpeta a la PC (por USB, memoria, etc.).
   Puedes usar el archivo impresora-visual.zip de la carpeta Download del telefono.
2. Descomprime el ZIP en una carpeta, por ejemplo:
   C:\Users\TuUsuario\Documents\proyectos\impresora visual
3. Abre el Panel de Control de XAMPP y pulsa Start en MySQL.
   Apache no es necesario para el portal.
4. Haz doble clic en instalar.bat
   El instalador revisa Node y MySQL, instala las dependencias,
   crea las cuentas de prueba y abre http://localhost:3000

Para abrir el portal los demas dias:
   - Inicia MySQL en XAMPP.
   - Haz doble clic en iniciar.bat

Base de datos:
   MySQL / MariaDB de XAMPP en 127.0.0.1:3306
   Usuario: root   Contrasena: (vacia, por defecto de XAMPP)
   Base: portal_pnf

Aplicacion de Visual Basic (opcional):
   Abre una terminal en vb\ComprobantesVB y ejecuta:  dotnet run
   Requiere el SDK de .NET en Windows.
